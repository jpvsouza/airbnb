# 📖 Manual do Hóspede (Welcome Book)

Manual digital e responsivo desenvolvido para hóspedes de acomodações do Airbnb. Permite acesso rápido a instruções de check-in, regras da casa, uso de aparelhos, cópia rápida de senha do Wi-Fi e dicas da região com links diretos para o Google Maps.

Hospedado gratuitamente via **GitHub Pages**.

---

## 🚀 Demonstração

Acesse a versão ao vivo: [https://SEU_USUARIO.github.io/NOME_DO_REPOSITORIO/](https://SEU_USUARIO.github.io/NOME_DO_REPOSITORIO/)

---

## ✨ Funcionalidades

- **Acesso rápido ao Wi-Fi:** Botão com cópia da senha para a área de transferência em um clique.
- **Contato direto com o Host:** Botão de WhatsApp pré-configurado com mensagem automática.
- **Navegação por âncoras:** Acesso instantâneo às seções (Check-in, Regras, Aparelhos e Dicas).
- **Instruções de Aparelhos:** Seções expansíveis (`details/summary`) para não poluir a tela.
- **Dicas Locais:** Links diretos para padarias, mercados e pontos de interesse no Google Maps.
- **Totalmente responsivo:** Otimizado para visualização em smartphones.
- **Zero build:** Sem dependências ou empacotadores (HTML5 + Tailwind CSS via CDN).

---

## 🛠️ Tecnologias

- **HTML5**
- **Tailwind CSS** (via CDN)
- **Font Awesome 6** (ícones)
- **JavaScript Vanilla** (lógica de cópia de senha e feedback visual)
